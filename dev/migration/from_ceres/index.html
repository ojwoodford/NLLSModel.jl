Migrating from Ceres Solver (C++)

Ceres Solver is an open-source C++ library for modeling and solving large nonlinear least squares problems.

Here is a direct mapping of Ceres Solver concepts to NLLSModel.jl:

Concept Translation Table

Ceres Solver (C++)NLLSModel.jl (Julia)Notes
ceres::ProblemModelContainer for variable blocks and cost/residual blocks
ceres::CostFunctionAbstractResidual / AbstractCostDefines residual vector & derivatives
ceres::LossFunctionAbstractRobustifierRobust M-estimator kernel (HuberKernel, Huber2oKernel, GemanMcclure2oKernel, etc.)
Parameter Block (double*)Variable (Float64, SVector, Vector, custom struct)Supports both immutable stack types and mutable arrays
ceres::ManifoldOptimizationVariableInterface.nvars & OptimizationVariableInterface.updateTangent-space manifold retraction
ceres::Solver::OptionsOptimizationOptions (NLLSOptions)Iterator, linear solver, tolerances, thread count
ceres::Solver::SummaryOptimizationResult (NLLSResult)Costs, timings, iteration/evaluation counts, allocations
ceres::Solve(options, &problem, &summary)optimvars(problem) + optimize (or NLLSsolver.optimize!)Core solve call

Ceres vs NLLSModel Code Comparison

Ceres Solver (C++):

struct CostFunctor {
  template <typename T>
  bool operator()(const T* const x, T* residual) const {
    residual[0] = 10.0 - x[0];
    return true;
  }
};

ceres::Problem problem;
double x = 0.5;
problem.AddResidualBlock(
    new ceres::AutoDiffCostFunction<CostFunctor, 1, 1>(new CostFunctor),
    new ceres::HuberLoss(1.0),
    &x);

ceres::Solver::Options options;
ceres::Solver::Summary summary;
ceres::Solve(options, &problem, &summary);

NLLSModel.jl (Julia):

using NLLSModel
using Static, StaticArrays

struct CostResidual <: AbstractResidual
    varind::Int
end
NLLSModel.ndeps(::CostResidual) = static(1)
NLLSModel.nres(::CostResidual) = static(1)
NLLSModel.varindices(r::CostResidual) = SVector(r.varind)
NLLSModel.getvars(r::CostResidual, vars::Vector) = (vars[r.varind]::Float64,)
NLLSModel.computeresidual(::CostResidual, x) = SVector(10.0 - x)
NLLSModel.robustkernel(::CostResidual) = Huber2oKernel(1.0)
Base.eltype(::CostResidual) = Float64

problem = Model(Float64, CostResidual)
idx = addvariable!(problem, 0.5)
addcost!(problem, CostResidual(idx))

options = OptimizationOptions(iterator = :levenbergmarquardt)
result = optimize!(problem, options) # Needs `using SecondOrderOptimization`; the solution is in problem.variables
